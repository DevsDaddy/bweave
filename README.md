# Welcome to BWeave
![bweave compression](img/cover.png)

The **BWeave** - powerful and small, advanced hybrid compression library for realtime applications written on pure TypeScript. Dependency-free and open-source production ready compression for client-server applications with any data types.

> The idea behind this library is to provide a fast, high-quality, lossless compression library for real-time applications operating on various data types. I'm not reinventing compression, just making it a bit more hybrid and easy to use.
